# Задача для Claude Code: браузер треклистов «Ночные ритмы» и «Атмосфера»

## Контекст

Я диджей-любитель (Pioneer DDJ + Rekordbox). У меня есть две базы треклистов радиошоу Max Popov (JungliSt), собранные с promodj.com/junglist:

- **«Ночные ритмы»** (Night Rhythms): лаунж, даунтемпо, ню-джаз, соул, 2005–2020. Файл `data/nr_eps.json`: 202 выпуска, 2337 позиций, 2210 уникальных треков.
- **«Атмосфера»** (Atmosphere): дип-хаус, 2009–2015. Файл `data/at_eps.json`: 142 выпуска, 1346 позиций, 1327 уникальных треков.

В папке `reference/prototype.html` лежит рабочий прототип на чистом JS (один файл, данные грузит из `data/`). Используй его как образец поведения и внешнего вида, но код пиши заново по требованиям ниже.

Нужно локальное веб-приложение, в котором я выбираю шоу, затем выпуск, вижу его треклист, выбираю трек и получаю по нему всю информацию. Пользоваться буду с ноутбука и с телефона, в том числе прямо на площадке.

## Данные

Оба файла имеют одинаковую структуру: это JSON-массив выпусков, уже отсортированный от новых к старым.

```json
[
  {
    "id": "7148200",
    "num": 282,
    "name": "Part 282",
    "title": "Night Rhythms part282 by JungliSt [24.10.20] #282",
    "date": "2020-10-23",
    "duration": "59:07",
    "styles": ["Easy Listening", "Downtempo"],
    "url": "https://promodj.com/junglist/radioshows/7148200/...",
    "kind": "episode",
    "alsoPlaylist": "https://promodj.com/junglist/playlists/15908",
    "tracks": [
      {
        "pos": 1,
        "artist": "Jehan",
        "title": "Pretty Track (Original Mix)",
        "base": "Pretty Track",
        "mix": "Original Mix",
        "label": "Star Creature Universal Vibrations",
        "k": "jehan|prettytrackoriginalmix"
      }
    ]
  }
]
```

Пояснения к полям:

- `num` — номер выпуска, может быть `null` (спецвыпуски, отдельные треклисты 2009 года).
- `kind` — `"episode"` (выпуск с аудио на PromoDJ) или `"playlist"` (только треклист, без аудио).
- `alsoPlaylist` — есть не всегда; ссылка на дублирующий треклист 2009 года.
- `date` — `YYYY-MM-DD`, может быть пустой строкой.
- `tracks` может быть пустым массивом (например, «Атмосфера» #62 — живая запись без треклиста). Показывать для такого выпуска понятное пустое состояние.
- `duration`, `label`, `mix` — могут быть пустыми строками.
- `styles` — стили **выпуска** по разметке PromoDJ, а не конкретного трека.
- `base` — название без версии, `mix` — версия или ремикс, если удалось выделить из скобок.
- `k` — нормализованный ключ трека: строчные буквы и цифры исполнителя и полного названия. Один и тот же трек в разных выпусках имеет одинаковый `k`. По нему считать повторы и связывать выпуски.

Данные не редактировать. Если нужна нормализация (например, склейка разного написания одного исполнителя), делать её в коде приложения отдельным слоем.

## Что построить

Одностраничное приложение без бэкенда. Стек: **Vite + React + TypeScript**, стили обычным CSS (CSS-переменные), без UI-фреймворков. Данные подключить как статические JSON (импорт или `fetch` из `public/data`). Всё должно работать офлайн после `npm run build` и открываться через `npm run preview` или любой статический сервер.

### Экран и навигация

Три колонки на десктопе, на телефоне — последовательные экраны с кнопкой «Назад».

1. **Выбор шоу.** Переключатель вверху: «Ночные ритмы» / «Атмосфера». У каждого шоу свой акцентный цвет. Рядом общее число выпусков и уникальных треков.
2. **Список выпусков.** Название (`name`), дата в формате `24.10.2020`, длительность, стили чипами, число треков. Фильтры: поиск по номеру или названию выпуска, год (выпадающий список из имеющихся годов), стиль выпуска. Выпуски типа `playlist` пометить значком «только треклист».
3. **Треклист выбранного выпуска.** Нумерованный список в порядке `pos`: исполнитель, название, лейбл серым. Рядом с треком бейдж «×N», если трек звучал в эфире больше одного раза (по `k` в обоих шоу). Над списком — заголовок выпуска, дата, стили и ссылка «Открыть на PromoDJ» (`url`, новая вкладка).
4. **Карточка трека** (выбор трека в треклисте открывает её справа или поверх на телефоне):
   - исполнитель, название, версия (`mix`), лейбл;
   - сколько раз звучал и **во всех каких выпусках обоих шоу** — списком с датами, каждый пункт кликабелен и открывает тот выпуск с подсвеченным треком;
   - позиция трека в текущем выпуске и соседние треки (предыдущий и следующий) — это помогает понять, как Max Popov строил переходы;
   - другие треки этого исполнителя в базе (по совпадению `artist` без учёта регистра);
   - кнопка «Скопировать» — копирует строку `Artist - Title` в буфер обмена;
   - ссылки поиска (новая вкладка): Beatport, Discogs, YouTube, Spotify, Bandcamp, SoundCloud, Juno Download. Запрос — `artist + base`, закодированный через `encodeURIComponent`.

### Глобальный поиск

Поле поиска в шапке ищет по исполнителю и названию трека сразу в обоих шоу. Результаты показывают трек, шоу и число эфиров; выбор открывает карточку трека.

### Состояние и ссылки

- Текущий выбор хранится в URL-хеше: `#nr/7148200/jehan|prettytrackoriginalmix` (шоу / id выпуска / ключ трека). Обновление страницы и ссылка, отправленная себе на телефон, открывают тот же экран.
- Последнее выбранное шоу запоминать в `localStorage`.

### «Мой сет» (корзина)

- В карточке трека и в треклисте кнопка «+ в сет».
- Отдельная панель «Мой сет»: список выбранных треков, перетаскивание для изменения порядка, удаление.
- Экспорт: кнопка «Скачать .txt» (строки `Artist - Title`) и «Скопировать список». Сет хранится в `localStorage`.

### Внешний вид

- Светлая и тёмная тема по системной настройке (`prefers-color-scheme`) плюс переключатель вручную.
- Адаптивность: нормально работает на ширине 375px, нет горизонтальной прокрутки страницы.
- Цифры в колонках — `font-variant-numeric: tabular-nums`.
- Клавиатура: стрелки вверх/вниз по списку выпусков и трекам, Enter открывает, Esc закрывает карточку.

## Требования к коду

- Разбить на компоненты: `ShowSwitcher`, `EpisodeList`, `Tracklist`, `TrackCard`, `GlobalSearch`, `SetPanel`.
- Индексы строить один раз при загрузке: `Map<k, вхождения[]>` по обоим шоу, `Map<artistLower, k[]>`.
- Типы данных описать в `src/types.ts` строго по схеме выше.
- Без внешних запросов, кроме ссылок, которые открывает сам пользователь.
- README на русском: как установить (`npm i`), запустить (`npm run dev`), собрать и открыть на телефоне в локальной сети (`npm run dev -- --host`).

## Критерии приёмки

1. Переключаюсь на «Атмосферу», выбираю #237 — вижу 10 треков в правильном порядке, первый Liro — La Nave (Original Mix).
2. В «Ночных ритмах» выбираю Part 282, трек Bar Blue — My Way (In the Lounge Mix) — в карточке «звучал 3 раза» и три выпуска: 282, 276, 266. Клик по 266 открывает Part 266 с подсвеченным треком.
3. Глобальный поиск «Sade» находит треки в обоих шоу.
4. Ссылка с хешем, открытая в новой вкладке, восстанавливает тот же выпуск и трек.
5. Добавляю 5 треков в сет, меняю порядок, скачиваю .txt — порядок в файле совпадает.
6. На ширине 375px всё читается и нажимается, горизонтальной прокрутки нет.
7. `npm run build` проходит без ошибок TypeScript.
