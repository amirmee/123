# Ночные ритмы и Атмосфера — браузер треклистов

Локальное приложение для просмотра треклистов радиошоу Max Popov (JungliSt):
«Ночные ритмы» (2005–2020) и «Атмосфера» (2009–2015). Без бэкенда, работает офлайн.

## Установка

Нужен Node.js 18 или новее.

```bash
npm i
```

## Запуск для разработки

```bash
npm run dev
```

Откроется адрес вида `http://localhost:5173`.

## Сборка и просмотр собранной версии

```bash
npm run build
npm run preview
```

`npm run build` проверяет типы TypeScript и складывает готовое приложение в `dist/`.
Папку `dist` можно открыть любым статическим сервером (например, `npx serve dist`); пути относительные,
так что подойдёт и подпапка. Открывать `dist/index.html` двойным кликом нельзя: браузер не даст загрузить базы с диска.

## Запуск в Docker

Нужен запущенный Docker Desktop. Node.js на компьютере для этого не нужен: сборка идёт внутри образа, раздаёт nginx.

```bash
docker compose up -d --build
```

Приложение откроется по адресу http://localhost:8080. Контейнер `nr-app` перезапускается сам вместе с Docker Desktop.

- Обновить после изменений в коде или базах: снова `docker compose up -d --build`.
- Остановить: `docker compose down`.
- Другой порт: поменяйте `8080` в `docker-compose.yml`.
- С телефона в той же сети Wi-Fi: `http://<IP компьютера>:8080` (IP показывает `ipconfig`).

## Открыть на телефоне в локальной сети

Ноутбук и телефон должны быть в одной сети Wi-Fi.

```bash
npm run dev -- --host
```

В консоли появится строка `Network: http://192.168.x.x:5173/` — откройте этот адрес на телефоне.
То же для собранной версии: `npm run preview -- --host` (порт 4173).
Если телефон не подключается, разрешите Node.js во входящих подключениях брандмауэра Windows.

## Как пользоваться

- Вверху переключатель шоу; последнее выбранное запоминается.
- Слева выпуски с фильтрами по номеру или названию, году и стилю. «Только треклист» — выпуск без аудио на PromoDJ.
- В центре треклист выпуска. «×N» — сколько раз трек звучал в эфире в обоих шоу.
- Карточка трека: все эфиры (клик открывает тот выпуск), соседние треки, другие треки исполнителя,
  кнопка «Скопировать» (`Artist - Title`) и ссылки поиска на Beatport, Discogs, YouTube, Spotify, Bandcamp, SoundCloud, Juno Download.
- Поиск в шапке ищет трек по исполнителю и названию сразу в обоих шоу.
- «+ в сет» добавляет трек в «Мой сет». Порядок меняется перетаскиванием за ручку ⋮⋮ (мышью или пальцем) или стрелками ↑↓.
  Экспорт: «Скачать .txt» и «Скопировать список». Сет хранится в браузере (`localStorage`).
- Текущий экран записан в адресе: `#nr/7148200/jehan|prettytrackoriginalmix` (шоу / выпуск / трек).
  Такую ссылку можно отправить себе на телефон.
- Клавиатура: ↑↓ по выпускам и трекам, Enter открывает, Esc закрывает карточку, сет или результаты поиска.
- Тема следует системной; кнопка ◐ переключает вручную.

## Устройство

```
data/                 исходные базы (не редактируются)
src/types.ts          типы по схеме данных
src/data.ts           загрузка и индексы: Map<k, вхождения[]>, Map<artist, k[]>
src/normalize.ts      слой нормализации (ключ исполнителя, текст для поиска)
src/route.ts          хеш ↔ состояние экрана
src/useSet.ts         «Мой сет»
src/components/       ShowSwitcher, EpisodeList, Tracklist, TrackCard, GlobalSearch, SetPanel
```

Базы подключаются как статические файлы: при сборке они копируются в `dist/assets` и загружаются без внешних запросов.
